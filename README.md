# Eaglercraft HTML

A browser-based Minecraft-like game built with HTML5, CSS, and JavaScript using Three.js.

## Features

- 🎮 First-person gameplay
- 🌍 Procedurally generated terrain
- 🌳 Trees and vegetation
- ⛏️ Block breaking and placement
- 💡 Dynamic lighting and shadows
- 📱 Responsive design

## Controls

- **WASD** - Move forward, left, backward, right
- **Space** - Jump
- **Mouse** - Look around (click to lock/unlock)
- **Left Click** - Break blocks
- **Right Click** - Place blocks

## Getting Started

1. Clone the repository:
```bash
git clone https://github.com/amirortizbrito-ai/eaglercraft-html.git
cd eaglercraft-html
```

2. Open `index.html` in a modern web browser (Chrome, Firefox, Edge, Safari)

3. Click the game window to lock your mouse and start playing

## Requirements

- Modern web browser with WebGL support
- Internet connection (for Three.js CDN)
